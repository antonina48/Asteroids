## Описание проекта

Лабораторная работа 3.4 «Астероиды».

Двумерная аркадная игра, разработанная на языке
Python с использованием библиотеки Tkinter.
Программа представляет собой двумерную аркадную игру,
разработанную на языке Python с использованием Tkinter.
Игрок управляет космическим кораблем, уничтожает
астероиды ракетами, набирает очки и избегает столкновений.

## Функциональные возможности

### Основной функционал

- Управление космическим кораблем с клавиатуры.
- Вращение, ускорение и постепенное торможение.
- Изменение изображения при включении двигателя.
- Стрельба ракетами с ограниченным временем жизни.
- Случайная генерация и вращение астероидов.
- Тороидальная геометрия игрового поля.
- Обработка столкновений игровых объектов.
- Тайловая анимация взрывов.
- Подсчет очков и количества жизней.
- Статический и динамический космические фоны.
- Стартовая заставка и повторный запуск игры.

### Дополнительный функционал

- Ограничение максимальной скорости корабля.
- Ограничение количества астероидов.
- Учет времени между кадрами.
- Программное создание графических ресурсов.




## Требования к системе

- Python 3.9 или выше.
- Windows / macOS / Linux.
- Tkinter — стандартная библиотека Python.
- Сторонние библиотеки не требуются.

Для Linux может потребоваться системный пакет python3-tk.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/Asteroids.git
cd Asteroids
```

### 2. Создание виртуального окружения

Перед созданием нового виртуального окружения
необходимо удалить локальную копию старой папки venv,
если она была получена при клонировании.

Windows:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

Дополнительные библиотеки не требуются.

### 4. Запуск программы

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| Стрелка влево | Поворот корабля влево |
| Стрелка вправо | Поворот корабля вправо |
| Стрелка вверх | Ускорение корабля |
| Space | Выстрел ракетой |
| Левая кнопка мыши | Запуск игры через заставку |

### Назначение основных модулей

- `main.py` — основная логика игры, интерфейс
  и обработка событий.
- `settings.py` — глобальные параметры игры.
- `models.py` — классы игровых объектов и физика.
- `graphics.py` — создание изображений, отрисовка
  объектов и тайловая анимация.
- `requirements.txt` — зависимости проекта.
- `screenshots/` — демонстрация работы программы.
- `venv/` — виртуальное окружение.

Разделение программы на четыре модуля позволяет
отделить настройки, физику, графику и игровую логику,
что упрощает чтение и сопровождение кода.

## Пример использования

1. Запустить программу командой `python main.py`.
2. Нажать на центральную заставку.
3. Управлять кораблем с помощью стрелок.
4. Уничтожать астероиды нажатием Space.
5. Получать очки за уничтоженные астероиды.
6. Избегать столкновений.
7. После окончания игры нажать на заставку
   для повторного запуска.
